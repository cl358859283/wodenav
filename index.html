数据备份与多端同步
!
WebDAV CORS 警告

浏览器安全策略要求 WebDAV 服务器允许跨域访问 (CORS)。很多私有云盘或 NAS 默认未开启 CORS，可能导致连接失败。

!
同步机制与认证警告

使用应用专用密码而非登录密码；数据以 JSON 明文存储于远程路径，请确保 WebDAV 访问权限仅限本人。连接失败时请检查 CORS 与路径是否正确。

配置将保存在本地浏览器，不会上传账号密码到本站。
!
同步机制与延迟警告

刷新页面：从云端拉取数据（智能合并本地新增）。

点击保存：将本地数据推送到云端（覆盖云端旧数据）。

CDN 延迟：保存后可能需 1-5 分钟生效，请勿频繁操作！

Token 与仓库配置仅保存在本地浏览器，不会上传到本站。
!
必须配置 CORS 策略

由于浏览器安全限制，你必须在 S3/R2 后台配置 CORS 规则，允许你自己的域名访问。具体配置请参考 docs/storage 文档或 Cloudflare R2 / 对象存储 CORS 说明。

Access Key 与配置仅保存在本地浏览器，不会上传到本站。
导出完整配置为 JSON（含分类链接 + 搜索引擎），可在其他设备导入恢复。适合临时备份或跨浏览器迁移。
导入将覆盖当前导航与搜索引擎数据，请先导出备份。支持本站导出的 JSON，或从导出的 data.js 中解析。
将当前配置导出为可直接替换仓库中的 js/data.js。推送到 Pages 后，新访客或其他设备清除本地数据即可使用最新默认导航，实现多端同步。
工作流：本页编辑 → 导出 data.js → 替换仓库 js/data.js → git push → 部署完成。其他设备点击下方「清除本地数据」后刷新即可加载新默认。

移除导航与搜索引擎相关 localStorage，下次加载使用站点 js/data.js 默认数据；主题、壁纸、侧边栏状态不受影响。
