# 常见问题

**Q: 换设备后看不到我加的链接？**  
A: 数据在浏览器本地。请用「导出 JSON / data.js」或 WebDAV / GitHub / S3·R2 同步，再在新设备导入或清本地后拉默认。

**Q: WebDAV 连接失败？**  
A: 检查 CORS、应用密码、路径是否正确；浏览器控制台通常会有跨域报错。

**Q: GitHub 保存失败？**  
A: Token 是否具备 `repo` 权限；路径是否指向文件而非目录；是否与远程冲突（可先拉取再保存）。

**Q: S3 / R2 连接或上传失败？**  
A: 1) 确认 Endpoint 与 Bucket 正确（R2 为 `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`）；2) 在存储后台配置 CORS，允许你的域名；3) 检查 Access Key 权限是否包含对象读写。

**Q: 本地壁纸不显示？**  
A: 确认文件在 `Landscape` / `Portrait` 下且已在 `LOCAL_WALLPAPERS` 登记；模式选「本地」；用开发者工具看图片 URL 是否 404。

**Q: 手机拖不动文件夹？**  
A: 需**长按约 0.4 秒**再拖，不要一碰就滑；长按成功后页面滚动会锁定。

**Q: 清除本地数据会丢主题和壁纸吗？**  
A: 不会。清除主要针对导航与搜索引擎缓存，外观类设置会保留。

**Q: 为什么必须用本地服务器打开？**  
A: 项目使用 ES Modules（`type="module"`），`file://` 协议下多数浏览器会拦截跨文件导入。
