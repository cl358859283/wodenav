# 设置面板总览

点击右下角 **设置** 按钮打开大弹窗，顶部标签：

| 标签 | 功能 |
|------|------|
| 添加链接 | 新增单条链接，或导入浏览器书签 HTML |
| 链接管理 | 搜索、批量操作、拖拽排序链接与分组 |
| 搜索引擎 | 管理搜索引擎列表 |
| 分类管理 | 新建大分类 / 二级分类，结构管理 |
| 外观设置 | 主题、首页布局、遮罩/卡片透明度、壁纸 |
| 同步 | WebDAV / GitHub / S3·Cloudflare R2 / 本地备份 / 部署同步 / 清除本地数据 |

关闭：右上角关闭按钮，或点击弹窗外遮罩。
