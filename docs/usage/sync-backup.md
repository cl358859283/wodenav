# 同步与备份

**设置 → 同步** → 选择 **存储类型**。

### 12.1 WebDAV

适合坚果云等支持 WebDAV 的网盘。

1. 填写 WebDAV URL、用户名、**应用专用密码**、文件路径（如 `/data.json`）。
2. **测试连接** → **上传到云端** / **从云端下载**。

注意：浏览器要求服务端开启 **CORS**；许多 NAS 默认未开。配置仅保存在本机浏览器。

### 12.2 GitHub 仓库

1. 创建 Personal Access Token（需要 **repo** 权限）。
2. 填写：Token、用户名、仓库名、分支（默认 `main`）、文件路径（如 `public/data.json`）。
3. **测试连接** / **保存到云端** / **从云端拉取**。

说明：

- 保存会覆盖远程文件（Contents API）。
- 若站点经 Pages / CDN 分发，生效可能需 1–5 分钟，请勿频繁推送。
- Token 与配置仅存本机，不会上传到导航站本身。

### 12.3 S3 / Cloudflare R2

兼容 AWS S3 API 的对象存储（Cloudflare R2、MinIO、各类 S3 兼容服务）。

1. **存储类型** 选择「S3 / Cloudflare R2」。
2. 填写：
   - **Endpoint**：如 `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`
   - **Access Key ID** / **Secret Access Key**
   - **Bucket** 名称
   - **Public URL**（可选，公开访问域名，便于壁纸直链）
   - **文件路径**（默认 `data.json`）
3. 在对象存储后台配置 **CORS**，允许你的站点源访问（`GET` / `PUT` / `HEAD`），否则浏览器会拦截请求。
4. 使用「测试连接」「上传到云端」「从云端下载」。

密钥仅保存在本机浏览器，不会上传到本站。

### 12.4 本地备份

| 操作 | 说明 |
|------|------|
| 导出 JSON | 完整备份（分类 + 搜索引擎），可拷到其他浏览器 |
| 导入 JSON | **覆盖**当前本地导航与搜索引擎；也支持解析本站导出的 `data.js` |

导入前建议先导出备份。

### 12.5 部署同步（导出 data.js）

用于把当前配置变成仓库默认数据：

1. 页面上编辑好分类、链接、搜索引擎。  
2. **导出 data.js**。  
3. 用下载文件**完整替换**仓库中的 `js/data.js`。  
4. `git add` → `commit` → `push`，等待 Pages 部署。  
5. 其他设备：**清除本地数据** → 自动刷新 → 加载最新默认。

### 12.6 清除本地数据

清除导航与搜索引擎相关缓存（主题、壁纸、布局等外观设置会保留）。  
刷新后重新读取 `js/data.js` 默认配置。
