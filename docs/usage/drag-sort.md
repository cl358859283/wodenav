# 拖拽排序（桌面 / 手机）

### 桌面

直接按住拖动：

| 位置 | 可拖内容 |
|------|----------|
| 文件夹模式主页 | 一级文件夹图标 |
| 文件夹对话框内 | 二级文件夹图标 |
| 直显模式 | 一级分组标题；二级标签（tab） |
| 链接管理 | 一级分组、二级分组、链接行 |
| 搜索引擎列表 | 引擎行 |

### 手机 / 平板

**长按约 0.4 秒**进入拖拽，再移动手指：

- 长按前轻微滑动仍可滚动页面（减少误触）。
- 进入拖拽后锁定页面滚动，并显示跟随手指的半透明预览。
- 松手完成排序；不会误触发点击打开。
- 支持设备有震动时，开始 / 完成会有轻微反馈。

顺序写入本地数据，主页、侧边栏、设置内列表保持一致。
