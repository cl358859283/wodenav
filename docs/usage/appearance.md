# 外观设置

**设置 → 外观设置**

### 11.1 主题模式

| 选项 | 说明 |
|------|------|
| 跟随系统 | 随系统浅色 / 深色切换 |
| 深色 | 固定深色 |
| 浅色 | 固定浅色 |

页头主题按钮可在浅色 / 深色间快速切换（会写入具体模式）。

### 11.2 首页布局

见 [5.3 两种首页布局](#53-两种首页布局)。

### 11.3 遮罩暗化

控制壁纸上方黑色（深色主题）或白色（浅色主题）遮罩浓度：

- `0%`：几乎无遮罩  
- 越高：壁纸越暗、前景文字越易读  
- 默认约 `48%`（与原先硬编码接近）

### 11.4 卡片透明度

控制链接卡片背景不透明度（**越低越透**）：

- `0%`：卡片背景全透明  
- `100%`：不透明  
- 默认约 `92%`

两项均实时生效，并保存在本地。

### 11.5 壁纸模式

| 模式 | 说明 |
|------|------|
| **默认** | 主题自带背景，不加载自定义图 |
| **本地** | 使用 `wallpaper/Landscape` 与 `wallpaper/Portrait` 中的图片 |
| **API** | 填写返回图片 URL 的接口，或图片直链；支持按横竖屏注入尺寸（如 Unsplash Source、Picsum） |
| **网络图片** | 输入图片直链，或本地上传生成 Data URL |

**本地模式 · 换一张**：在当前设备方向对应的壁纸池中切换下一张。  
**方向自适应**：手机竖屏优先 `Portrait/`，桌面横屏优先 `Landscape/`；旋转屏幕会自动换池。

文件夹模式打开的分类对话框为**透明玻璃**风格，壁纸可透出。

详细本地目录说明见 [第 14 节](#14-本地壁纸配置)。
