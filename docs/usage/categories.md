# 分类管理

**设置 → 链接管理**

### 10.1 新建

- **大分类**（一级文件夹）：输入名称 → 创建。
- **二级分类**：选择所属大分类 + 名称 → 创建。  
  每个大分类至少保留一个二级分类。

### 10.2 重命名 / 删除

在链接管理列表中，一级 / 二级标题行右侧为图标按钮：

- **重命名**（铅笔图标）：在标题处直接编辑，回车确认，Esc 取消，失焦也会保存。
- **删除**（垃圾桶图标）：删除大分类会移除其下所有二级分类与链接；删除二级分类时至少保留一个。

### 10.3 排序

可通过拖拽一级分组、二级分组进行排序（详见拖拽排序文档）。
