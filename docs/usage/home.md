# 主页使用

### 5.1 搜索

- 顶部搜索框：选择搜索引擎后输入关键词，回车搜索。
- 「本站」引擎：在当前页面链接中本地过滤（不跳转外站）。
- 引擎列表可在 **设置 → 搜索引擎** 中增删、排序、标记「火箭」（外链打开）。

### 5.2 侧边栏

- 展示一级分类，点击可跳转到对应区域（直显模式）或打开分类（文件夹模式）。
- 手机 / 平板：左上角按钮打开抽屉侧边栏，点遮罩关闭。

### 5.3 两种首页布局

在 **设置 → 外观设置 → 首页布局** 切换：

| 布局 | 说明 |
|------|------|
| **文件夹模式** | 主页只显示一级分类文件夹图标；点击进入透明对话框，再选二级目录查看链接 |
| **直显模式** | 主页直接展示所有一级分类与二级标签、链接，适合内容较少时一览 |

### 5.4 链接卡片

- 点击打开网站。
- 长按或通过设置可编辑 / 删除（见链接管理）。
