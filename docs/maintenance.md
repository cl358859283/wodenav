# 维护对照表

| 想改什么 | 改哪里 |
|----------|--------|
| 默认网站 / 分类 | `js/data.js` → `DEFAULT_DATA`，或页面编辑后导出 data.js |
| 默认搜索引擎 | `js/data.js` → `DEFAULT_ENGINES` |
| 本地壁纸列表 | `js/config.js` → `LOCAL_WALLPAPERS` + `wallpaper/Landscape` / `Portrait` |
| 颜色主题 | `css/variables.css` |
| 布局间距、文件夹样式 | `css/layout.css` |
| 卡片 / 弹窗 / 设置样式 | `css/components.css` |
| 手机适配 | `css/responsive.css` |
| 交互与功能逻辑 | `js/app.js`（入口）及 `state.js` / `render.js` / `manage.js` 等 |
| 主题 / 外观滑块 | `js/theme.js` |
| 壁纸逻辑 | `js/wallpaper.js` |
| 长按拖拽等工具 | `js/utils.js` |
| 弹窗交互 | `js/dialogs.js` |
